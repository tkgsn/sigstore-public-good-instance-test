Rekor v2 Append & Verify

GitHub Actionsが署名対象をRekor v2へappendし、検証者がbundleから署名者・時刻・Merkle treeへの包含を確認する流れ。

1

Subjectを作る

commit・workflow・run IDを含むJSONを署名対象として生成する。

GITHUB ACTIONS
2

身元と鍵を結ぶ

GitHub OIDCをFulcioが確認し、一時公開鍵とworkflow identityを結ぶ短期証明書を発行する。

FULCIO
3

Hashを署名する

SubjectのSHA-256を一時秘密鍵でECDSA署名し、TSAからRFC 3161 timestampを取得する。

COSIGN + TSA
4

Entryを提出する

digest・signature・Fulcio certificateをhashedrekord 0.0.2として提出する。

COSIGN → REKOR
5

Merkle treeへappend

Entryを追記し、log index・audit path・root hash・signed checkpointを返す。

REKOR V2
1

Subject digest

手元のsubjectをSHA-256化し、bundleのmessageDigestと一致するか確認する。

2

Identity & signature

Fulcio chainとGitHub workflow identityを検証し、証明書の公開鍵でECDSA署名を確認する。

3

Trusted time

RFC 3161 tokenをTSA trust rootで検証し、署名がFulcio証明書の有効期間内に存在したことを確認する。

4

Leaf hash

SHA256(0x00 || canonicalizedBody)でRekor entryのleaf hashを再計算する。

5

Inclusion proof

20個のaudit-path hashを順に合成し、checkpointに記載されたroot hashへ到達することを確認する。

6

Signed checkpoint

TUF TrustedRootのRekor Ed25519鍵でcheckpoint署名を検証し、root hashを信頼できる状態にする。
